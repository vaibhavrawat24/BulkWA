Setup

Connect your WhatsApp Business API

API Credentials

  1. Create a Meta Developer Account

    Go to developers.facebook.com and sign in with your Facebook account.

  2. Create an App

    Click "Create App" → Select "Business" type → Fill in your app name.

  3. Add WhatsApp Product

    Inside your app dashboard, click "Add Products" → Find "WhatsApp" → Click "Set Up".

  4. Get Your Phone Number ID

    Go to WhatsApp → API Setup. You'll see your Phone Number ID under the "From" section.

  5. Get a Permanent Access Token

    Go to Business Settings → System Users → Create a System User → Generate a token with whatsapp_business_messaging permission. Copy this token.

  6. Create a Message Template

    Go to WhatsApp Manager → Message Templates → Create Template. Submit for approval. This usually takes a few minutes to 24 hours.
