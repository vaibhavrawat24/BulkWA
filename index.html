  1. Create a Meta Developer Account

    Go to developers.facebook.com and sign in.

  2. Create an App

    Click "Create App" → Select "Business" → Fill in your app name.

  3. Add WhatsApp Product

    Inside your app → "Add Products" → WhatsApp → Set Up.

  4. Get Your Phone Number ID

    Go to WhatsApp → API Setup. Copy the Phone Number ID shown.

  5. Get a Permanent Access Token

    Business Settings → System Users → Create user → Generate token with whatsapp_business_messaging permission.

  6. Create a Message Template

    WhatsApp Manager → Message Templates → Create & submit for approval. Takes a few minutes to 24 hours.
